# Beispiel: Textile im Markdown

Normales **Markdown** davor.

## Beschreibung (Redmine-Textile)

```textile
*Ausgangslage*

Text mit @code@ und einer Liste:

* eins
* zwei

Zeile eins
Zeile zwei (einfacher Zeilenumbruch wie in Redmine)

|_. Bild |_. Hinweis |
|!beispiel.png!|Bild nur per Dateiname, liegt in bilder/|

{{collapse(Technische Hinweise)
*Geprüft*

* Punkt im Aufklappbereich
}}
```

Danach wieder *Markdown*.
