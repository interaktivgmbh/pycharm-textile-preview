Normal **Markdown** before the block.

```textile

* one
* two

Line one
Line two (a single line break, as in Redmine)

|_. Image |_. Note |
|!example.png!|Image given by file name only, it lives in images/|

{{collapse(Technical notes)

* Item inside the collapsed section
}}
```
